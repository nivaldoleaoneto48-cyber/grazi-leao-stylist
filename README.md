# Grazi Leão — Stylist

Site estático em português com portfólio no Instagram e contatos por WhatsApp e e-mail.

## Publicar na Vercel

Importe este repositório, selecione o preset **Other**, mantenha a raiz do projeto em `./` e deixe o comando de build vazio. Os arquivos estão prontos para servir, sem dependências.

## Desenvolvimento

Abra `index.html` para visualizar. Edite `style.css` para alterar a apresentação e `app.js` para as interações.

A imagem de abertura é ilustrativa. O formulário prepara mensagens no canal escolhido sem armazenar dados.
